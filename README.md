# ecommerce
Java Spring Boot E-Commerce Application

Storefront (Customer Area)
Shop Front: Browse featured products and view full inventory listings.
Product Page: Detailed views with dynamic product info and media assets.
Shopping Cart Page: Interactive cart to add, modify, or remove items.
Checkout Page: Streamlined order processing and billing interface.
Order Status / Ordered Page: Clear summary and confirmation for completed orders.

Admin Dashboard (Management Area)
Control Dashboard: Centralized metrics and system control overview.
User Management: Admin controls for managing customer accounts and access permissions.
Product Management: Complete CRUD operations for inventory management and image uploads.
Order Management: System to view, process, and update customer order statuses.

Tech Stack
Backend: Java, Spring Boot (MVC Framework)
Frontend: Responsive HTML, CSS, Bootstrap
